# Бот приёма заявок: воронка с измеренной конверсией

Бот, который принимает заявки из мессенджера, вытаскивает контакт из свободного текста
и передаёт заявку менеджеру. Состояние диалога хранится явно, каждый переход пишется
в журнал — поэтому в любой момент видно, сколько заявок дошло и где остальные встали.

Пример собран на нише остекления балконов: лиды приходят с Авито и Директа,
задача — получить телефон и записать на замер.

## Цифры

Прогон на потоке из 200 диалогов, похожих на живые: кто-то пишет всё одним сообщением,
кто-то по шагам, кто-то спрашивает цену и уходит, часть обращений — жалобы.

| Показатель | Значение |
|---|---|
| Диалогов с контактом | 151 из 200 |
| Доведено до заявки | **151 из 151 (100 %)** |
| Телефон распознан верно | **151 из 151 (100 %)** |
| Шагов до заявки | 2,1 в среднем |
| Эскалаций к человеку | 25 |

В потоке намеренно есть трудные случаи: номер среди других чисел («балкон 6 метров,
бюджет до 150000, 8(912)345.67.89»), номер с припиской «звоните после 18», номер,
продиктованный словами. Все разбираются верно.

## Как это выглядит

```
— Здравствуйте
— бот: Подскажите, что нужно — остекление, отделка или замер?
— Нужно остекление балкона
— бот: Оставьте номер телефона, чтобы мастер связался и уточнил детали.
— Ирина, +7 912 345-67-89
— бот: Ирина, записал: остекление балкона. Мастер позвонит на +79123456789.
```

Всё одним сообщением — бот не переспрашивает:

```
— балкон 6 метров, бюджет до 150000, 8(912)345.67.89
— бот: записал. Мастер позвонит на +79123456789 в ближайшее рабочее время.
```

Жалоба уходит человеку, а не обрабатывается ботом:

```
— хочу жалобу оставить, мастер не приехал
— бот: Передаю ваше обращение руководителю, с вами свяжутся.
```

## Решения, которые дают результат

**Состояние диалога хранится явно, а не «помнится» моделью.** Заявка — это запись
с полями и журналом переходов. Поэтому видно, где человек остановился, и можно
посчитать конверсию по этапам, а не гадать.

**Один вопрос за раз.** Если спросить сразу имя, телефон и адрес, значительная часть
людей не отвечает вовсе. Бот спрашивает недостающее по одному и не переспрашивает то,
что уже получил.

**Телефон ищется по форме номера, а не как первая цепочка цифр.** В сообщении рядом
стоят метраж, бюджет, номер дома и часы работы — и «до 150000» легко принять за телефон.
Кандидаты проверяются по структуре: код страны, код оператора, длина.

**Жалобы не обрабатываются автоматически.** Слова «жалоба», «верните деньги»,
«директор» сразу переводят диалог на человека: бот, спорящий с недовольным клиентом,
приносит больше вреда, чем пользы.

## Как запустить

```bash
python contacts.py     # разбор контактов на примерах
python evaluate.py     # прогон 200 диалогов и метрики
```

| Файл | Что делает |
|---|---|
| `contacts.py` | Извлечение телефона и имени из свободного текста |
| `funnel.py` | Воронка: состояния, переходы, журнал, эскалация |
| `evaluate.py` | Поток диалогов и замер конверсии |

Подключение к Telegram — это обёртка над `handle()`: состояние уже отделено
от транспорта, поэтому тот же код работает и в другом мессенджере.
